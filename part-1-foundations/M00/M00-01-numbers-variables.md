# M00-01. 수, 변수와 상수

## 이 단원이 필요한 이유

AI 논문의 수식에는 숫자와 문자가 함께 등장한다. 같은 문자라도 어떤 식에서는 입력이고, 다른 식에서는 모델이 학습할 파라미터다. 계산을 시작하기 전에 무엇이 바뀌고 무엇이 고정되는지 구분하지 못하면 식의 의미를 따라가기 어렵다.

예를 들어 다음과 같은 식을 보게 될 수 있다.

\[
s=wx+b
\]

이 식에서 $x$는 입력, $w$와 $b$는 모델이 학습한 값일 수 있다. 한 번의 예측에서는 $w$와 $b$를 고정한 채 $x$를 바꾸지만, 학습과정을 분석할 때는 $w$와 $b$도 변한다. 따라서 문자 모양만 보고 변수와 상수를 정할 수 없다. 어떤 계산을 설명하는지 먼저 확인해야 한다.

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 수, 값과 기호를 구분해 설명한다.
- 식에서 변수와 상수를 찾아 그 역할을 말한다.
- 변수에 특정 값을 넣어 간단한 식을 계산한다.
- 입력, 파라미터와 하이퍼파라미터가 어떤 문맥에서 변하거나 고정되는지 구분한다.

## 선수지식 확인

별도의 선수 단원은 없다. 다음 계산을 할 수 있으면 시작할 수 있다.

- 정수의 덧셈과 곱셈
- 음수와 분수의 기본 계산
- 괄호가 있는 식에서 괄호 안을 먼저 계산하기

계산이 익숙하지 않아도 각 예제의 중간 단계를 따라가면 된다.

## 기호와 용어

| 기호·용어 | Common spoken reading | 이 단원에서의 의미 |
|---|---|---|
| $3$ | `three` | 특정한 수를 나타내는 숫자 기호 |
| $x$ | `x` | 여러 값을 나타낼 수 있는 변수 |
| $c$ | `c` | 문맥 안에서 고정된 값을 나타내는 상수 |
| $\theta$ | `theta` | 모델이 학습하는 파라미터에 자주 쓰는 기호 |
| $\eta$ | `eta` | 학습률과 같은 하이퍼파라미터에 자주 쓰는 기호 |

그리스 문자라고 해서 항상 상수인 것은 아니다. 라틴 문자라고 해서 항상 변수인 것도 아니다. 기호의 역할은 식 주변의 정의와 문맥이 결정한다.

## 핵심 개념

### 수, 값과 기호

수(number)는 셈, 순서와 크기 등을 표현하는 수학적 대상이다. 다음은 모두 수다.

\[
3,\qquad -2,\qquad \frac12,\qquad 0.75
\]

종이에 쓰는 $3$이라는 모양은 수를 나타내는 기호다. 같은 수를 3, 3.0, $6/2$처럼 서로 다르게 표현할 수도 있다. 표현이 달라도 계산 결과가 같다면 같은 값을 나타낼 수 있다.

값(value)은 어떤 수나 수학적 대상이 현재 나타내는 내용이다. 예를 들어 $x$에 3을 넣었다면 $x$의 값은 3이다.

| 구분 | 내용 |
|---|---|
| 기호 | $x$ |
| 현재 값 | 3 |

기호와 값은 같은 것이 아니다. 기호 $x$는 그대로 두고 값만 3, 4, -1처럼 바꿀 수 있다.

### 변수

변수(variable)는 허용된 여러 값 중 하나를 나타낼 수 있는 기호다. 변수는 상황에 따라 여러 역할을 한다.

- 아직 모르는 값을 나타낸다.
- 함수에 넣을 입력 자리를 나타낸다.
- 시간이나 위치에 따라 달라지는 양을 나타낸다.
- 학습 중 갱신되는 모델 파라미터를 나타낸다.

변수라는 말이 반드시 시간이 흐르면서 값이 움직인다는 뜻은 아니다. 한 계산에서 $x=3$으로 정해 놓더라도, 다른 값을 넣을 수 있는 자리로 $x$를 사용했다면 $x$는 변수다.

### 상수

상수(constant)는 정해진 문맥 안에서 고정된 값이다.

다음 식을 보자.

\[
2x+1
\]

여기서 $x$는 여러 값을 넣을 수 있는 변수다. 숫자 2와 1은 이 식에서 고정돼 있으므로 상수다.

상수가 반드시 숫자로 직접 쓰이는 것은 아니다. 다음처럼 문자로 이름을 붙일 수 있다.

\[
cx+1
\]

문제에서 “$c=2$로 고정한다”고 정했다면 $c$는 그 문맥에서 상수다. 반대로 $c$를 학습하거나 여러 값으로 바꾸어 조사한다면 $c$는 분석 대상인 변수가 된다.

따라서 변수와 상수의 구분은 문자의 생김새가 아니라 다음 질문으로 결정한다.

> 지금 설명하는 계산에서 이 값이 달라질 수 있는가, 아니면 고정돼 있는가?

### 변수에 값을 넣기

변수에 특정 값을 정해 계산하는 것을 이 단원에서는 “값을 넣는다”고 표현한다. 다음 식에 $x=3$을 넣어보자.

\[
2x+1
\]

$x$가 있던 자리를 3으로 바꾼다.

\[
2\cdot3+1
\]

곱셈을 먼저 계산하면

\[
6+1=7
\]

이다. 변수 $x$의 값이 달라지면 결과도 달라질 수 있다.

| $x$의 값 | $2x+1$의 값 |
|---:|---:|
| 0 | 1 |
| 1 | 3 |
| 3 | 7 |
| -1 | -1 |

이 표에서 식 $2x+1$의 구조는 그대로이고 $x$의 값만 바뀐다.

### 문맥이 바뀌면 역할도 바뀐다

다시 간단한 모델 식을 보자.

\[
s=wx+b
\]

지금은 이 식을 “$w$와 $x$를 곱한 뒤 $b$를 더해 점수 $s$를 만든다”고 읽으면 충분하다.

한 번의 예측을 설명할 때는 다음과 같이 볼 수 있다.

| 기호 | 역할 | 한 번의 예측에서 |
|---|---|---|
| $x$ | 입력 | 새 데이터에 따라 달라질 수 있다. |
| $w$ | 학습된 파라미터 | 현재 모델에서는 고정한다. |
| $b$ | 학습된 파라미터 | 현재 모델에서는 고정한다. |
| $s$ | 출력 점수 | 입력과 파라미터로 계산된다. |

하지만 학습과정을 설명할 때는 $w$와 $b$를 바꾸면서 더 나은 값을 찾는다. 이 문맥에서는 $w$와 $b$가 학습 중 변하는 변수다.

> 한 번의 예측에서는 파라미터를 고정하고 입력에 따른 출력을 계산한다. 모델을 학습할 때는 파라미터를 바꾸면서 손실을 줄인다.

이 차이는 나중에 모델의 학습과정을 해석할 때 반복해서 사용한다.

## 예제 1. 변수에 값을 넣어 계산하기

### 문제

다음 식에서 변수와 상수를 구분하고, $x=-2$일 때의 값을 구하라.

\[
3x+4
\]

### 풀이

$x$에는 여러 값을 넣을 수 있으므로 변수다. 숫자 3과 4는 식 안에서 고정돼 있으므로 상수다.

$x=-2$를 넣으면

\[
3x+4
=
3\cdot(-2)+4
\]

가 된다. 곱셈부터 계산한다.

\[
3\cdot(-2)=-6
\]

따라서

\[
-6+4=-2
\]

이다.

### 결과의 의미

식의 구조와 상수 3, 4는 바뀌지 않았다. 변수 $x$의 값을 -2로 정했기 때문에 전체 식의 값이 -2로 계산됐다.

## 예제 2. 모델 식에서 역할 구분하기

### 문제

다음 모델에서 $w=0.8$, $b=0.1$, $x=2$라고 하자.

\[
s=wx+b
\]

점수 $s$를 계산하고, 한 번의 예측에서 무엇이 입력이고 무엇이 고정된 파라미터인지 설명하라.

### 풀이

주어진 값을 식에 넣는다.

\[
s
=
0.8\cdot2+0.1
\]

곱셈부터 계산하면

\[
0.8\cdot2=1.6
\]

이므로

\[
s=1.6+0.1=1.7
\]

이다.

이 예측에서 $x$는 입력이고, $w$와 $b$는 현재 모델의 파라미터다. 한 번의 예측을 계산하는 동안에는 세 값 모두 구체적으로 정해져 있지만, 새 입력을 넣으면 $x$가 달라진다. 모델을 다시 학습하면 $w$와 $b$도 달라질 수 있다.

### 결과의 의미

문자의 역할은 “지금 숫자가 정해져 있는가”만으로 판단하지 않는다. 어떤 범위의 계산을 설명하는지 확인해야 한다.

## AI 수식에서 자주 만나는 세 역할

### 입력

입력(input)은 모델에 주는 데이터다. 보통 $x$를 많이 사용한다. 이미지, 문장, 센서값처럼 실제 입력은 여러 숫자로 이루어질 수 있지만, 지금은 하나의 값으로 생각한다.

### 파라미터

파라미터(parameter)는 모델이 학습을 통해 조정하는 값이다. $w$, $b$, $\theta$ 같은 기호를 자주 사용한다.

- 한 번의 예측에서는 현재 파라미터를 고정한다.
- 학습과정에서는 파라미터를 갱신한다.

### 하이퍼파라미터

하이퍼파라미터(hyperparameter)는 보통 학습 알고리즘을 실행하기 전에 사람이 정하거나 별도의 탐색으로 선택하는 값이다. 학습률 $\eta$가 대표적인 예다.

한 학습 실행에서 $\eta$를 고정할 수 있지만, 서로 다른 실험에서는 $\eta$를 바꾸어 결과를 비교할 수 있다. 따라서 하이퍼파라미터도 모든 상황에서 절대적인 상수인 것은 아니다.

## 흔한 오해

### 오해 1. 문자는 변수고 숫자는 상수다

숫자 2와 3은 고정된 값을 직접 나타내지만, 문자도 상수를 나타낼 수 있다. $c=2$로 고정했다고 선언했다면 $c$는 해당 문맥에서 상수다.

### 오해 2. 변수는 시간에 따라 계속 움직여야 한다

변수는 여러 가능한 값을 나타낼 수 있는 기호다. 한 문제에서 $x=3$으로 정해 계산하더라도 $x$라는 자리가 다른 값을 받을 수 있다면 변수 역할을 한다.

### 오해 3. 파라미터는 항상 상수다

학습을 마친 모델로 예측할 때는 파라미터를 고정한다. 그러나 학습과정을 분석할 때는 파라미터가 반복해서 갱신된다. 같은 대상의 역할이 분석 범위에 따라 달라진다.

### 오해 4. 그리스 문자는 상수다

$\pi$처럼 상수에 자주 쓰는 그리스 문자도 있지만, $\theta$는 모델 파라미터, $\eta$는 학습률, $\lambda$는 규제 강도처럼 여러 역할에 사용된다. 기호의 모양만으로 역할을 결정하지 않는다.

## 연습문제

### 1. 변수와 상수 찾기

다음 식에서 변수와 상수를 구분하라.

\[
5x-2
\]

<details>
<summary>해설 보기</summary>

$x$에는 여러 값을 넣을 수 있으므로 변수다. 5와 -2는 식 안에서 고정된 값이므로 상수다.

5는 $x$에 곱해지는 고정값이고, -2는 곱셈 결과에 더해지는 고정값이다. 숫자의 위치나 연산이 달라도 이 식에서 고정돼 있다는 점은 같다.

</details>

### 2. 값 넣어 계산하기

다음 식에 $x=-2$를 넣어 값을 구하라.

\[
5x-2
\]

<details>
<summary>해설 보기</summary>

$x$가 있던 자리를 -2로 바꾼다.

\[
5\cdot(-2)-2
\]

곱셈을 먼저 계산하면

\[
5\cdot(-2)=-10
\]

이다. 따라서

\[
-10-2=-12
\]

가 된다. 답은 -12다.

</details>

### 3. 같은 식에 다른 값 넣기

$2x+1$에 $x=0$, $x=2$, $x=-3$을 각각 넣어 결과를 구하라. $x$가 달라질 때 변하지 않는 것은 무엇인지 설명하라.

<details>
<summary>해설 보기</summary>

$x=0$이면

\[
2\cdot0+1=1
\]

이다. $x=2$이면

\[
2\cdot2+1=5
\]

이다. $x=-3$이면

\[
2\cdot(-3)+1=-5
\]

이다.

결과는 1, 5, -5로 달라진다. 그러나 식의 구조와 상수 2, 1은 변하지 않는다. 변수 $x$의 값만 바뀌었다.

</details>

### 4. 모델 식 읽기

다음 식에서 $x$, $w$, $b$, $s$가 한 번의 예측에서 맡는 역할을 설명하라.

\[
s=wx+b
\]

<details>
<summary>해설 보기</summary>

- $x$는 모델에 들어가는 입력이다.
- $w$는 입력에 곱해지는 학습된 파라미터다.
- $b$는 곱셈 결과에 더하는 학습된 파라미터다.
- $s$는 입력과 파라미터로 계산한 출력 점수다.

한 번의 예측에서는 현재 $w$와 $b$를 고정하고 입력 $x$에 대한 $s$를 계산한다. 학습과정을 설명한다면 $w$와 $b$도 갱신되는 변수가 된다.

</details>

### 5. 문맥에 따라 판단하기

다음 설명에서 $\theta$, $x$, $\eta$의 역할을 구분하라.

> 모델은 데이터 $x$를 입력받는다. 학습 중 파라미터 $\theta$를 갱신한다. 이번 학습 실행에서는 학습률 $\eta=0.01$을 끝까지 유지한다.

<details>
<summary>해설 보기</summary>

- $x$는 입력 데이터다. 학습 예제가 바뀌면 값도 달라질 수 있다.
- $\theta$는 학습되는 파라미터다. 학습 중 반복해서 갱신되므로 학습과정에서는 변수다.
- $\eta$는 이번 실행에서 0.01로 고정한 하이퍼파라미터다. 따라서 이번 실행 안에서는 상수로 취급한다.

다른 실험에서 $\eta$를 바꾸어 비교할 수 있으므로 $\eta$가 모든 문맥에서 절대적인 상수라는 뜻은 아니다.

</details>

### 6. 주장 판단하기

다음 주장이 맞는지 판단하고 이유를 설명하라.

> 그리스 문자로 쓰인 값은 상수이고, 라틴 문자로 쓰인 값은 변수다.

<details>
<summary>해설 보기</summary>

틀린 주장이다. 문자 종류는 관례를 도울 뿐 역할을 결정하지 않는다.

$\theta$는 학습되는 모델 파라미터로 자주 사용하므로 변수가 될 수 있다. 반대로 $c$는 “constant”의 첫 글자를 따서 고정된 값을 나타내는 데 자주 사용한다. 변수인지 상수인지는 기호의 모양이 아니라 해당 문맥에서 값이 달라질 수 있는지로 판단한다.

</details>

## 단원 요약

- 수는 값을 나타내는 수학적 대상이고, 기호는 그 수나 다른 대상을 표시한다.
- 변수는 여러 가능한 값을 나타낼 수 있으며, 상수는 정해진 문맥에서 고정된다.
- 변수에 값을 넣을 때는 변수가 있던 자리를 해당 값으로 바꾸어 계산한다.
- 입력, 파라미터와 하이퍼파라미터는 서로 다른 역할을 맡는다.
- 같은 파라미터도 한 번의 예측에서는 고정되고 학습과정에서는 변할 수 있다.
