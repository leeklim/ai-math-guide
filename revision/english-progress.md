## 원문 모호성 — 보존하고 별도 확인할 항목

- M03-11 ReLU 입력 방향 그림의 캡션 `h₁+2h₂=0`은 입력 변화 방향의 성분을 뜻하지만 본문에서는 h가 층 출력 함수 이름이기도 하다. 영문에서도 기호를 유지했다. 기호를 v 등으로 바꾸려면 한국어 원문 정정까지 포함하는 별도 결정이 필요하다.
- 교육과정 N05-22의 `causal inference`는 autoregressive inference 문맥의 제목이다. 통계적 인과 추론과 혼동될 여지가 있으나 번역자가 임의로 확정 제목을 바꾸지 않는다.
- 용어집 LayerNorm 행은 `variance로 scale`이라 쓰지만 N05-18의 기준식은 표준편차에 해당하는 `sqrt(variance + epsilon)`로 나눈다. 영문 용어집은 원문 표현을 보존했다. 이 정의를 정정하려면 한국어·영어 용어집을 함께 수정하는 별도 결정이 필요하다.
- M00-04는 로그 눈금을 다음 단원에서 다룬다고 안내하지만 M00-05에는 전용 로그 눈금 설명이 없다. 기존 안내를 영문에 보존하고 단원 연결 정정은 별도로 남긴다.
- M00-06의 양 끝을 포함하는 인덱스 개수 `b−a+1`은 `a≤b`를 암묵적으로 전제한다. 원문의 범위를 영어에서 임의로 확장하거나 빈 범위 규칙을 추가하지 않는다.
- M00-08 예제 5의 일부 속성 복원 설명과 `d(f(x))≈x`의 전체 입력 표기가 정확히 대응하지 않는다. M00-10 문제 7의 shape 오류 단정에는 `d=C` 예외가 빠져 있다. 영문에서 가정·수식·정답을 임의로 보충하거나 주장을 강화하지 않는다.
- M00-10 문제 8의 작은 cross entropy를 원문 결함 후보로 남겼던 판단은 메인과 독립 검토자가 재검토하여 철회했다. 정규화된 이산 분포에서 `H(T,S)=H(T)+KL(T||S)`이고 `H(T)≥0`이므로 작은 절대 CE는 평균 KL도 제한한다. loss 감소만으로 같은 결론을 내리는 경우와 구분하며, 모든 표본의 보장은 원문의 오해 4에서 이미 제한한다. 한국어·영어 단원 파일은 수정하지 않았다.
- M00-08의 역수 설명은 `1/f(x)`를 제시하고도 같은 위첨자 −1이 나타난다고 말한다. 해당 식에는 위첨자가 없으므로 원문 문구 점검 후보로 남긴다.
- M00-10의 증류 설명은 바깥 음수 부호를 제외한 ‘안쪽 합’을 `−log p_S`의 가중평균이라 부른다. 전체 표본 loss의 의도는 분명하지만 문자 그대로의 안쪽 합에는 부호 차이가 있으므로 원문 문구 점검 후보로 남긴다.
- M01-04의 증가·감소 구간과 도함수 그래프의 축 위·아래를 연결한 문장은 고립된 도함수 0을 배제하지 않아 일반화가 강하다. 영문은 원문 주장을 보존하며 한국어 정정은 별도로 남긴다.
- M01-06은 `g(x)=x` 조건이 없으면 `f'(g(x))`와 `f'(x)`가 다르다고 단정한다. 바깥 도함수가 상수인 경우 등에는 같을 수 있으므로 원문 문구의 점검 후보로 남긴다. 영문에서 임의로 조건을 새로 넣지 않는다.
- M02-08 문제 5는 kernel이 두 벡터의 span이라고만 주고, 해설에서는 두 독립 방향을 전제한다. 두 생성 벡터의 독립성·nonzero 조건은 문제에 명시되지 않았다. 메인도 해당 원문 문제와 해설을 확인했으며 번역자가 조건을 몰래 추가하지 않는다.
- 용어집 sharpness 행은 base rate에서 벗어나는 정도로 쓰지만 M04-15 핵심 개념 8은 prediction distribution 자체의 집중으로 설명하고 constant 0.99도 sharp하다고 명시한다. 메인과 독립 검토자가 이 원문 간 정의 차이를 확인했다. 영문 용어집과 단원은 각각 원문의 의미를 보존하며 양언어 정의 정정은 별도 결정으로 남긴다.
- M04-13 오해 3의 outcome probability 차이와 뒤의 pointwise 차이는 절대 probability mass, 상대/log-ratio, continuous density 중 어떤 차이인지 분명하지 않다. 메인이 해당 문단과 이산·연속 범위를 확인했다. 영문에서 상대차이로 몰래 확정하거나 새 정리를 넣지 않으며 원문 문구의 별도 확인 후보로 남긴다.
- M04-15 예제 4는 표본이 충분히 크면 관측 빈도가 0.7이라고 쓰지만 문제 1은 유한 표본의 빈도가 예측 확률과 정확히 같을 필요가 없다고 설명한다. 메인과 독립 검토자가 해당 원문을 확인했다. 영문은 각각의 문구를 보존하며 유한 표본의 근사·극한 표현 정정은 별도 확인 후보로 남긴다.

## 사이트 구현의 알려진 제한

- 공개용 PowerShell wrapper와 Pages workflow는 아직 기존 한국어 출력 경로를 유지한다. 전권 영문 완료 뒤 최종 공개 준비 단계에서 검증된 한영 병합 산출물과 완료 대장 gate를 연결해야 한다. 현재 수동 locale CLI와 로컬 병합 preview는 작동하며, 원격 실행·업로드는 하지 않았다.
- 설치된 Material 9.7.7은 페이지별 `rel=alternate` 주소 아래의 sitemap을 자동 요청한다. 깊은 단원 경로의 실패는 빈 sitemap으로 처리한다. 정적 언어 링크는 `target="_self"`로 이 테마의 URL 재작성에서 제외되며 필수 same-page hreflang은 유지한다. 개발자 도구에는 불필요한 sitemap 요청 오류가 나타날 수 있다. 실제 전환 기능은 별도 화면 검수로 확인한다.
