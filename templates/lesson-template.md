# M00-00. 단원 제목

## 이 단원이 필요한 이유

이 개념이 뒤의 수학이나 모델 해석에서 어떤 문제를 해결하는지 1~3문단으로 설명한다. 중요하다고 선언하는 대신 실제 사용처를 제시한다.

## 학습 목표

이 단원을 마치면 다음을 할 수 있다.

- 관찰 가능한 행동으로 작성한다.
- `이해한다`만 쓰지 않고 설명, 계산, 판단 또는 설계할 대상을 적는다.
- 목표는 3~5개로 제한한다.

## 선수지식 확인

필요한 선수 단원과 확인 질문을 적는다.

- 선수 단원: [M00-00 단원 이름](../경로.md)
- 확인 질문: 학습자가 이미 할 수 있어야 하는 일을 묻는다.

선수지식이 부족할 때 돌아갈 단원을 안내한다.

## 핵심 개념

### 직관

정의를 대신하지 않는 짧은 직관을 제시한다.

### 정확한 정의

개념이 성립하는 대상과 조건을 명시한다.

### 시각적 직관

공간 관계, 계산 흐름이나 비교 구조를 그림으로 보아야 이해가 빨라지는 경우에만 사용한다. 그림이 필요하지 않으면 이 절을 생략한다.

## 예제 1. 손으로 계산하기

### 문제

작은 수를 사용해 핵심 개념을 직접 계산하게 한다.

### 풀이

사용할 개념을 먼저 밝히고 계산을 한 단계씩 전개한다.

### 결과의 의미

계산 결과가 개념적으로 무엇을 뜻하는지 설명한다.

## 예제 2. 모델에서 찾기

실제 신경망 수식 또는 작은 모형에서 같은 구조가 어디에 나타나는지 보여준다. 아직 모델 관련 선수지식이 없는 초반 단원에서는 짧은 미리보기로 제한한다.

## 선택 실습

### 목적

실습으로 확인할 개념을 적는다.

### 준비물

- 데이터
- 코드 환경
- 필요한 라이브러리

### 수행

재현 가능한 순서로 작성한다.

### 예상 결과

숫자를 고정하기 어렵다면 결과의 모양과 확인 기준을 적는다.

### 해석 질문

- 결과에서 직접 말할 수 있는 것은 무엇인가?
- 추가 증거 없이 말할 수 없는 것은 무엇인가?

기초 단원에서 실습이 필요하지 않으면 이 절을 생략한다.

## 단원 요약

- 새로 배운 사실을 3~5개로 정리한다.
- 도입부의 문장을 그대로 반복하지 않는다.
- 다음 단원으로 이어지는 개념을 밝힌다.
