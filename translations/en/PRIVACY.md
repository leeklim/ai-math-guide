# Privacy & Analytics

Updated: 2026-10-08

You can read this textbook without signing up. The site operator uses Cloudflare Web Analytics to check traffic and page performance. This site does not use Google Analytics (GA4).

## Visit and page-view statistics

Cloudflare measures visits, page views, loading times, and web performance. Reports also group statistics by page path, referring site, country, device type, browser, and operating system. Visits do not count unique people, and one visit can include several page views. See the definitions of [metrics](https://developers.cloudflare.com/web-analytics/data-metrics/high-level-metrics/) and [report dimensions](https://developers.cloudflare.com/web-analytics/data-metrics/dimensions/).

Cloudflare states that it does not use cookies or localStorage to collect usage statistics, or fingerprint individuals using IP addresses or browser information. See [Cloudflare's privacy explanation](https://www.cloudflare.com/web-analytics/).

Your browser sends analytics data to Cloudflare servers. The site operator reads statistics in the Cloudflare dashboard and does not build individual browsing histories or use them for advertising targeting. Analytics runs only at the public textbook address, not in local previews. See [Cloudflare's Privacy Policy](https://www.cloudflare.com/privacypolicy/) for its information handling and retention practices.

You can block Cloudflare analytics requests with browser content-blocking features or extensions. Blocking analytics does not prevent you from reading the textbook. Blocking and transmission failures can cause statistics to undercount actual traffic.

## Browser preferences and external services

The textbook interface may store reading preferences, such as the theme, in your browser. The site does not use these values as personal identifiers for analytics.

GitHub Pages serves the website, and the site loads MathJax from an external CDN to display equations. Your browser sends requests to these services as well. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and the [UNPKG service information](https://unpkg.com/) for information about these services.

The interface loads fonts from Google Fonts. These font requests are separate from Google Analytics. See [Google Fonts' privacy information](https://developers.google.com/fonts/faq/privacy) for its handling practices.

For questions about the site, use the [textbook's GitHub repository](https://github.com/leeklim/ai-math-guide). Do not include passwords or sensitive personal information in public posts.
