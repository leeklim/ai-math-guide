# Mathematics and Methods for Model Interpretability

This curriculum starts with reading mathematical notation and progresses to neural network representations, causal interventions, learning dynamics, and advanced theory.

## Four parts

| Part | Stages | Purpose |
|---|---|---|
| Part 1 | 0–4 | Mathematical notation, calculus, linear algebra, probability, statistics, and information theory |
| Part 2 | 5 | The actual computations in neural networks and Transformers |
| Part 3 | 6–8 | Interpreting representations, causal effects, mechanisms, and learning dynamics |
| Part 4 | 9 | Optional advanced study in geometry, dynamics, symmetry, learning theory, and related topics |

## Production principles

- Markdown is maintained as the sole source.
- Equations use LaTeX notation.
- HTML is generated from Markdown and is not edited directly.
- Each lesson includes prerequisites, concepts, worked examples, exercises, solutions, and pass criteria.
- Executable labs are included from Part 2 onward.
- Terminology and mathematical notation are consistent across the curriculum.
- The Common spoken reading column in each Symbols and terms table uses actual English academic speech and is checked automatically.
- The progress record and glossary are updated when a new lesson is completed.
