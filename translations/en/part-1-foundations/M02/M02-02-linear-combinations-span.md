# M02-02. Linear combinations and span

## Why this lesson matters

Many neural network computations multiply vectors by numbers and then add them. A neuron's weighted input sum, attention's weighted value sum, and sums of feature directions all have this structure. The span describes which vectors can be produced from the given vectors.

Understanding span lets us determine whether given directions generate an entire plane, remain on one line, or can represent a target vector. It is a starting point for subspaces, bases, rank, and SVD.

## Learning objectives

After completing this lesson, you will be able to:

- Define and calculate linear combinations of vectors.
- Describe geometrically the span generated by one or two vectors.
- Use coefficient equations to determine whether a target vector belongs to a given span.
- Explain how redundant generating vectors can make representations nonunique.
- Read a neural network weighted sum as a linear combination and distinguish the claims it supports.

## Symbols and terms

| Symbol or term | Common spoken reading | Meaning | Conditions |
|---|---|---|---|
| $c_i$ | `c sub i` | Coefficient multiplying the $i$th vector | $c_i\in\mathbb R$ |
| $\sum_{i=1}^{k}c_i\mathbf v_i$ | `sum over i from one to k of c sub i v sub i` | Linear combination of $k$ vectors | All $\mathbf v_i$ have the same dimension. |
| $\operatorname{span}\{\mathbf v_1,\ldots,\mathbf v_k\}$ | `the span of v one through v k` | Set of all possible linear combinations | $\mathbf v_i\in\mathbb R^n$ |
| Generating vector | `generating vector` | Vector used to form linear combinations | Belongs to the same vector space. |

## Core concept 1. A linear combination adds scalar multiples

For $\mathbf v_1,\ldots,\mathbf v_k\in\mathbb R^n$ and real numbers $c_1,\ldots,c_k$, the expression

\[
c_1\mathbf v_1
+c_2\mathbf v_2
+\cdots
+c_k\mathbf v_k
\]

is a linear combination of the vectors. In summation notation, write

\[
\sum_{i=1}^{k}c_i\mathbf v_i
\]

Each coefficient $c_i$ determines how much of its vector to use and in which direction. A positive coefficient uses the same direction, a negative coefficient uses the opposite direction, and 0 leaves that vector unused.

## Core concept 2. Span allows every possible coefficient

The span of vectors $\mathbf v_1,\ldots,\mathbf v_k$ is

\[
\operatorname{span}\{\mathbf v_1,\ldots,\mathbf v_k\}
=
\left\{
\sum_{i=1}^{k}c_i\mathbf v_i
\;\middle|\;
c_1,\ldots,c_k\in\mathbb R
\right\}
\]

This is not one vector made using particular coefficients. It is the set of every vector obtainable by varying all real coefficients. The condition on the right inside the braces means that the coefficients can be chosen freely among real numbers.

The generating vectors $\mathbf v_1,\ldots,\mathbf v_k$ stay fixed; the coefficients vary. Choosing every coefficient as 0 gives the zero vector, so the zero vector belongs to every span. Choosing one coefficient as 1 and all others as 0 gives that generating vector, so each generating vector itself also belongs to the span.

## Core concept 3. The span of one nonzero vector is a line through the origin

If $\mathbf v\ne\mathbf 0$,

\[
\operatorname{span}\{\mathbf v\}
=
\{c\mathbf v\mid c\in\mathbb R\}
\]

Varying $c$ gives every multiple in the same or opposite direction as $\mathbf v$. In $\mathbb R^2$ or $\mathbb R^3$, these form a line through the origin.

Using only the zero vector gives

\[
\operatorname{span}\{\mathbf 0\}
=
\{\mathbf 0\}
\]

because multiplying it by any real number still gives the zero vector.

The marked coefficients below are only a few examples on the line. Continuously varying the real coefficient gives the whole line, whereas using the zero vector leaves only the origin.

## Core concept 4. Two distinct directions can generate a plane

In $\mathbb R^2$, if two vectors do not lie on the same line through the origin, combining their directions can produce every vector in the plane. For example, let

\[
\mathbf e_1=
\begin{bmatrix}1\\0\end{bmatrix},
\qquad
\mathbf e_2=
\begin{bmatrix}0\\1\end{bmatrix}
\]

For any $\mathbf x=\begin{bmatrix}x_1\\x_2\end{bmatrix}$,

\[
\mathbf x=x_1\mathbf e_1+x_2\mathbf e_2
\]

so

\[
\operatorname{span}\{\mathbf e_1,\mathbf e_2\}
=
\mathbb R^2
\]

Two directions other than the standard axes can play the same role. To make any target $(b_1,b_2)^\top$ using $(1,1)^\top$ and $(1,-1)^\top$ from Example 2, require $c_1+c_2=b_1$ and $c_1-c_2=b_2$. Adding and subtracting the equations gives $c_1=(b_1+b_2)/2$ and $c_2=(b_1-b_2)/2$. These coefficients can be chosen for any real target coordinates, so the two directions span all of $\mathbb R^2$.

By contrast, if the first vector is nonzero and the second is its real multiple, it adds no new direction. A negative multiple points the arrow the other way but only along the other half of the same line. If exactly one generating vector is zero, the other still generates only a line. If both are zero, only the zero vector remains.

## Core concept 5. Span membership is a coefficient-finding problem

To determine whether a target $\mathbf b$ belongs to $\operatorname{span}\{\mathbf v_1,\ldots,\mathbf v_k\}$, look for real coefficients $c_1,\ldots,c_k$ satisfying

\[
c_1\mathbf v_1+\cdots+c_k\mathbf v_k=\mathbf b
\]

Writing the equality componentwise gives a system of equations. If at least one solution exists, $\mathbf b$ belongs to the span; if none exists, it does not. We study systematic methods for solving such systems in M02-06.

## Core concept 6. Span is closed under addition and scalar multiplication

Suppose $\mathbf x$ and $\mathbf y$ belong to the same span. If

\[
\mathbf x=\sum_i a_i\mathbf v_i,
\qquad
\mathbf y=\sum_i b_i\mathbf v_i
\]

then

\[
\mathbf x+\mathbf y
=
\sum_i(a_i+b_i)\mathbf v_i
\]

is another linear combination of the same vectors. For any scalar $\alpha$,

\[
\alpha\mathbf x
=
\sum_i(\alpha a_i)\mathbf v_i
\]

so it also belongs to the same span.

The property that addition and scalar multiplication do not take results outside the set is called closure. A span is a representative example of a subspace. We study subspace conditions more generally in M03-05.

Adding the two points below or multiplying one by a negative coefficient leaves the result on the same line. Each result is represented without generating a new direction.

## Core concept 7. More generating vectors need not give unique representations

If

\[
\mathbf v_3=\mathbf v_1+\mathbf v_2
\]

the same vector can be represented as

\[
\mathbf v_3
\]

or

\[
\mathbf v_1+\mathbf v_2
\]

Redundant directions among the generating vectors can allow multiple coefficient choices.

For the same list $(\mathbf v_1,\mathbf v_2,\mathbf v_3)$, the first representation has coefficients $(0,0,1)$ and the second has $(1,1,0)$. The lists differ, but the resulting sum vector is the same. Adding $\mathbf v_3$ as a generator also leaves the span unchanged because $\mathbf v_1,\mathbf v_2$ already generate it.

Span describes only the set of vectors that can be produced. Uniqueness of representation depends on linear independence of the generators, which we study in M02-07.

## Example 1. Calculate a linear combination

For

\[
\mathbf v_1=
\begin{bmatrix}1\\2\end{bmatrix},
\qquad
\mathbf v_2=
\begin{bmatrix}3\\-1\end{bmatrix}
\]

the combination $2\mathbf v_1-\mathbf v_2$ is

\[
2
\begin{bmatrix}1\\2\end{bmatrix}
-
\begin{bmatrix}3\\-1\end{bmatrix}
=
\begin{bmatrix}2\\4\end{bmatrix}
-
\begin{bmatrix}3\\-1\end{bmatrix}
=
\begin{bmatrix}-1\\5\end{bmatrix}
\]

## Example 2. Check whether a target belongs to a span

Let

\[
\mathbf v_1=
\begin{bmatrix}1\\1\end{bmatrix},
\qquad
\mathbf v_2=
\begin{bmatrix}1\\-1\end{bmatrix},
\qquad
\mathbf b=
\begin{bmatrix}4\\2\end{bmatrix}
\]

Writing $c_1\mathbf v_1+c_2\mathbf v_2=\mathbf b$ componentwise gives

\[
c_1+c_2=4
\]

\[
c_1-c_2=2
\]

Adding gives $2c_1=6$, so $c_1=3$, and the first equation gives $c_2=1$.

\[
\mathbf b=3\mathbf v_1+\mathbf v_2
\]

Thus, $\mathbf b$ belongs to the two vectors' span.

## Example 3. A vector that adds no new direction

For

\[
\mathbf v_1=
\begin{bmatrix}1\\2\end{bmatrix},
\qquad
\mathbf v_2=
\begin{bmatrix}2\\4\end{bmatrix}
\]

we have $\mathbf v_2=2\mathbf v_1$. For any coefficients $a,b$,

\[
a\mathbf v_1+b\mathbf v_2
=
(a+2b)\mathbf v_1
\]

so every linear combination of the two vectors is a multiple of $\mathbf v_1$.

\[
\operatorname{span}\{\mathbf v_1,\mathbf v_2\}
=
\operatorname{span}\{\mathbf v_1\}
\]

There are two generators but only one direction.

## Example 4. A neural network weighted sum

For three value vectors $\mathbf v_1,\mathbf v_2,\mathbf v_3\in\mathbb R^d$ and weights $a_1,a_2,a_3$, the expression

\[
\mathbf z
=
a_1\mathbf v_1+a_2\mathbf v_2+a_3\mathbf v_3
\]

is a linear combination of the three vectors. Therefore,

\[
\mathbf z
\in
\operatorname{span}\{\mathbf v_1,\mathbf v_2,\mathbf v_3\}
\]

Attention weights usually have the additional constraints of being nonnegative and summing to 1. The achievable outputs can therefore be more restricted than the whole span. Span membership establishes representability using certain vectors, not causal evidence that the model uses a particular meaning.

The figure below illustrates these constraints with three two-dimensional value vectors. Compare the plane obtainable with unrestricted real coefficients with the triangular region obtainable using nonnegative weights summing to 1.

## Common misconceptions

### Misconception 1. Span is the result of adding the vectors once

Span is not one vector. It is the set of linear combinations obtainable with all real coefficients.

### Misconception 2. The generator count is the dimension of the span

Vectors that are multiples repeat a direction. Even three generators can provide only one or two independent directions.

### Misconception 3. Two vectors always span the whole plane

Even in $\mathbb R^2$, two vectors that are multiples generate only one line. In $\mathbb R^3$, two nonparallel vectors generally generate a plane through the origin, not the entire space.

### Misconception 4. A representation in a feature span means the model uses those features

Span membership establishes algebraic representability. Establishing actual necessity for model behavior requires evidence from removal, patching, or other interventions.

### 2. The span of one vector

For

\[
\mathbf v=
\begin{bmatrix}2\\-1\end{bmatrix}
\]

select every vector belonging to $\operatorname{span}\{\mathbf v\}$.

\[
\mathbf a=
\begin{bmatrix}6\\-3\end{bmatrix},
\qquad
\mathbf b=
\begin{bmatrix}-4\\2\end{bmatrix},
\qquad
\mathbf c=
\begin{bmatrix}2\\1\end{bmatrix}
\]

<details>
<summary>Show solution</summary>

Since $\mathbf a=3\mathbf v$ and $\mathbf b=-2\mathbf v$, both belong to the span. Matching the first component of $\mathbf c$ requires coefficient 1, but its second component is $1$ rather than $-1$, so it is not a multiple of $\mathbf v$.

</details>

### 3. Representation using the standard basis

Use

\[
\mathbf e_1=
\begin{bmatrix}1\\0\end{bmatrix},
\qquad
\mathbf e_2=
\begin{bmatrix}0\\1\end{bmatrix}
\]

to express $\begin{bmatrix}-3\\5\end{bmatrix}$ as a linear combination.

<details>
<summary>Show solution</summary>

\[
\begin{bmatrix}-3\\5\end{bmatrix}
=
-3\mathbf e_1+5\mathbf e_2
\]

The first coefficient is the first coordinate, and the second is the second coordinate.

</details>

### 4. Equations for span membership

For

\[
\mathbf v_1=
\begin{bmatrix}1\\2\end{bmatrix},
\qquad
\mathbf v_2=
\begin{bmatrix}2\\1\end{bmatrix},
\qquad
\mathbf b=
\begin{bmatrix}5\\4\end{bmatrix}
\]

solve $c_1\mathbf v_1+c_2\mathbf v_2=\mathbf b$ to determine whether $\mathbf b$ belongs to the span.

<details>
<summary>Show solution</summary>

The component equations are

\[
c_1+2c_2=5,
\qquad
2c_1+c_2=4
\]

The first gives $c_1=5-2c_2$; substituting into the second gives $10-4c_2+c_2=4$. Thus, $c_2=2$ and $c_1=1$.

\[
\mathbf b=\mathbf v_1+2\mathbf v_2
\]

Therefore, $\mathbf b$ belongs to the span.

</details>

### 5. Redundant generating vectors

For

\[
\mathbf v_1=
\begin{bmatrix}1\\0\end{bmatrix},
\qquad
\mathbf v_2=
\begin{bmatrix}2\\0\end{bmatrix}
\]

give two different linear combinations representing $\begin{bmatrix}4\\0\end{bmatrix}$.

<details>
<summary>Show solution</summary>

For example,

\[
\begin{bmatrix}4\\0\end{bmatrix}
=
4\mathbf v_1+0\mathbf v_2
\]

and

\[
\begin{bmatrix}4\\0\end{bmatrix}
=
0\mathbf v_1+2\mathbf v_2
\]

Since $\mathbf v_2=2\mathbf v_1$, the generating direction is redundant, and the coefficients are not unique.

</details>

### 6. Check closure

If $\mathbf x,\mathbf y\in\operatorname{span}\{\mathbf v_1,\mathbf v_2\}$, use coefficients to show that $2\mathbf x-3\mathbf y$ belongs to the same span.

<details>
<summary>Show solution</summary>

For some real $a_1,a_2,b_1,b_2$, write

\[
\mathbf x=a_1\mathbf v_1+a_2\mathbf v_2,
\qquad
\mathbf y=b_1\mathbf v_1+b_2\mathbf v_2
\]

Then

\[
2\mathbf x-3\mathbf y
=
(2a_1-3b_1)\mathbf v_1
+
(2a_2-3b_2)\mathbf v_2
\]

The new coefficients are real, so the result belongs to the same span.

</details>

### 7. A model connection and critique of claims

An activation $\mathbf h$ has been found to lie in the span of directions $\mathbf f_1,\mathbf f_2$. Evaluate each statement.

1. At least one coefficient pair satisfies $\mathbf h=c_1\mathbf f_1+c_2\mathbf f_2$.
2. The model necessarily uses $\mathbf f_1$ and $\mathbf f_2$ causally when producing predictions.

<details>
<summary>Show solution</summary>

The first statement is the definition of span and is correct. The second does not follow from span membership alone. Representability and use in the actual computation are different claims. Causal use requires investigating how behavior changes when those directions are removed or altered.

</details>

## Lesson summary

- A linear combination multiplies vectors in the same space by real coefficients and adds them.
- Span is the set of all possible linear combinations.
- The span of one nonzero vector is a line through the origin.
- Determine target membership by solving for coefficients that produce the target.
- Redundant generating directions can make linear-combination representations nonunique.
- A weighted sum's membership in a span establishes representability, not causal use.
